# Upstream Baseline

This repository starts from the Cockpit Tools 1.3.10 release source that matched the verified Windows installer used for the initial LDXP build.

- Upstream repository: https://github.com/jlcodes99/cockpit-tools
- Upstream version: 1.3.10
- Verified source commit: `b331b093ca07793688619142932ed22b28bd5979`

The upstream tag was later moved and its historical parent is no longer available from the upstream remote. The private LDXP source history therefore begins with a root import commit while retaining this immutable source reference.
